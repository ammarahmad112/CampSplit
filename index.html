🛠 Admin panel

Create a private view-only link for each friend. They see only the parts you tick, and can change nothing, and they never see this panel, backups or Drive settings. Remove someone to stop their link working. Links open on any device with a web browser: phones, tablets, laptops, smart TVs and Xbox (Edge). For Xbox or a TV, paste the link into tinyurl.com first to get a short link that’s easy to type, and use the 📺 button for big-screen mode.

☁️ Google Drive sync

Keeps your trip in your own Google Drive folder, so every device you connect shows the same data.
How to set it up (about 3 minutes)
  1. In Google Drive, create a folder (for example Camp Split Data). Open it and copy the folder ID from the address bar, the text after /folders/.
  2. Go to script.google.com, choose New project, delete what is there and paste the script below. Put your folder ID and a secret access code at the top.
  3. Choose Deploy, then New deployment, then type Web app. Set Execute as: Me and Who has access: Anyone. Deploy and approve the permissions.
  4. Copy the Web app URL (it ends with /exec), paste it above with your access code and press Connect. Do the same on any other device.
